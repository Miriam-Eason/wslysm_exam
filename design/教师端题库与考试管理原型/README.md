当前功能、设计取舍、模拟数据边界和后续待确认项见 [CURRENT_DEMO.md](CURRENT_DEMO.md)。

## 功能与交互

- 名称、科目与创建教师即时搜索；多关键词用空格分隔。
- `/` 聚焦搜索框，`Esc` 退出或清空。
- 科目筛选、排序、置顶、分页。
- 方案 B 第二版额外演示：我的题库/系部共享切换、添加共享题库、已有或自定义科目、移动端抽屉导航与筛选底部面板。
- 新建、编辑、删除、置顶菜单为可操作演示。
- 199 条示例数据；真实数据规模来自测试账号实测。

## 验证

- Chrome 桌面：1440 × 900。
- Chrome 窄屏：方案 A/C 为 375 × 812，方案 B 第二版为 393 × 852；`scrollWidth` 均未超过视口。
- 搜索“面点2.4 熟制”得到 35 条；筛选“面点技艺”得到 121 条。
- 分页、菜单、新建弹窗和 `/` 快捷键通过自动化交互检查。
- B 第二版验证了系部题库搜索、添加后来源标记、自定义科目创建、移动端抽屉导航、筛选底部面板、弹窗滚动锁定和右侧创建日期。
- 考试管理使用账号实测规模：156 条进行中、13 条已下架；支持状态、练习类型、班级、科目组合筛选、搜索、排序与分页。
- 侧栏筛选项始终保留；当前组合下为 0 的选项以灰色禁用呈现，并使用 0.3 秒颜色过渡。
- 手机端整行进入成绩统计，显示作答人数；成绩统计支持学生列表和答题详情。
- 新建考试采用四步流程：基本信息、题库与组卷方式、班级、确认；支持整库、快捷、明细三种组卷界面。
- 考试管理在 1440 × 900 和 393 × 852 下无横向溢出；移动筛选、抽屉导航均通过。
- 新建考试流程包含基本信息、题库与组卷方式、班级、确认四步；支持整库、快捷和明细组卷演示。
- 成绩统计覆盖总体指标、分数段、每题准确率和学生成绩，并提供学生错题详情。
- 考试科目缺少真实字段；设计假定的 `subjectSnapshot`、来源题库与历史数据迁移边界见 `exam-data-notes.md`。
- 浏览器运行无控制台错误。
