# 六个候选与三张方向卡

## 候选一｜最佳设计师：Dieter Rams · 功能主义索引

- **逻辑与来源**：以 Rams 的“少但更好”和 Vitsœ 606 收纳系统的秩序感为起点，不模仿其外观。
- **借的是什么**：信息逐项对齐、控件克制、没有为了装饰而存在的容器；所有层级由字号、间距和列结构完成。
- **主角素材**：题库名称与真实规模数字。
- **骨架**：单栏检索区 + 紧凑表格 + 分页。
- **胆量花在哪**：几乎不用卡片，让数据行本身成为界面。
- **form 来自内容的哪里**：题库是管理记录，不是营销内容；记录应当按列比较。

## 候选二｜最佳设计师：原研哉 · 留白式目录

- **逻辑与来源**：以“空”承托信息，不靠边框密集分隔；参考目录和索引的阅读节奏。
- **借的是什么**：大块留白、单一主列、以段落标题组织内容。
- **主角素材**：题库名称与科目分组。
- **骨架**：纵向目录，按科目分组，组内是简洁的行；顶部只有搜索。
- **胆量花在哪**：主动放弃首屏“信息越多越好”，用较大的组间距表达分类。
- **form 来自内容的哪里**：大量题库的自然层级先是科目，再是具体题库。

## 候选三｜现实参照：Linear 搜索与 Issue 列表

- **逻辑与来源**：同媒介参考 Linear 的高密度工作列表和搜索优先交互。
- **借的是什么**：搜索位于主要操作区；行高紧凑；元数据右对齐；键盘入口明确。
- **主角素材**：搜索结果和题库状态。
- **骨架**：命令式搜索栏 + 表格 + 轻量筛选。
- **胆量花在哪**：搜索比“新建题库”更早出现、更宽。
- **form 来自内容的哪里**：教师来此页的第一目的通常是找到已有题库，而不是创建。

## 候选四｜现实参照：macOS Finder · 列表视图

- **逻辑与来源**：macOS Finder 的侧栏分类 + 主列表，是桌面用户已熟悉的两级浏览模型。
- **借的是什么**：左侧固定科目导航、右侧结果列表、置顶/最近区域、选中态清晰。
- **主角素材**：科目计数与筛选后的题库列表。
- **骨架**：搜索栏 + 左右分栏，左侧课程导航，右侧列表。
- **胆量花在哪**：让科目导航常驻，而不是藏进下拉框。
- **form 来自内容的哪里**：题库天然依附课程/科目，分类是用户理解题库的第一层线索。

## 候选五｜秒数轮盘：电影感声波可视化（轮盘 8）

- **逻辑与来源**：从风格库抽取的“电影感声波可视化”，转译为焦点模式。
- **借的是什么**：暗背景、单一聚焦区、动态波形作为选中反馈。
- **主角素材**：当前搜索结果。
- **骨架**：搜索结果全屏聚焦，侧栏收起。
- **胆量花在哪**：用暗色工作图层与现有产品形成鲜明切换。
- **form 来自内容的哪里**：查找本身就是一个“聚焦”动作。

## 候选六｜秒数轮盘：上海摩登装饰艺术（轮盘 4）

- **逻辑与来源**：从风格库抽取的几何装饰语言，只取“几何秩序”和“强分组标题”，去掉年代装饰。
- **借的是什么**：有限的色块、明确的组标题、规则的三栏节奏。
- **主角素材**：题库卡片的科目标识与题目数量。
- **骨架**：检索条 + 按科目分段的紧凑卡片书架 + 分页。
- **胆量花在哪**：每个科目组拥有独立的浅色识别区。
- **form 来自内容的哪里**：199 个题库不是一条无差别清单，而是一排排可辨认的课程书架。

## 入选完整版

1. **方向 A｜检索优先型**：候选一 + 候选三，选 Rams 的克制和 Linear 的搜索效率。
2. **方向 B｜课程导航型**：候选四，保留 Finder 的两级浏览逻辑。
3. **方向 C｜分类书架型**：候选六，保留卡片熟悉感，但用科目分段、紧凑密度和分页避免长滚动。

候选二和候选五保留为备选，本阶段不制作完整版。
